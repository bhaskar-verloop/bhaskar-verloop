### 🎯 What I Own

> Quality from requirement to release — not just writing tests, but driving the process across both chat and bot product areas.

- 🧩 **Automation framework** — design & maintain a Playwright/Java/TestNG suite (live chat, bot recipes, outreach, reports, settings & dashboard); **100+ automation tickets delivered**
- ✍️ **Test authoring & maintenance** — convert manual repros, Jira tickets & product flows into idiomatic regression tests, and keep suites green and flake-free through product change (React 18 race conditions, UI additions, Answerflow enhancements)
- 🏃 **Execution & triage** — run suites, parse reports, and root-cause failures across locator drift, async-timing flake, env/data issues & genuine product bugs
- 🧪 **Feature validation across environments** — sign off features end-to-end on **Stage & UAT** before release (response-time metrics, system variables, agent working hours, user-preference persistence)
- 🐞 **Bug discovery & defect lifecycle** — filed **50+ detailed, reproducible defects** across Reports, Bot Builder, Outreach & Livechat; structured Jira tracking (Epics → Tasks → Sub-tasks → Bugs) with a maintained test inventory
- 📊 **Reporting & visibility** — actionable test reports (ExtentReports) and build-health signals for the team
- ⚙️ **CI/CD ownership** — keep GitHub Actions workflows current & green (e.g. Node.js 24 upgrade)
- 🤖 **QA + AI** — built Claude coding & executor agents for autonomous test creation, execution & triage
